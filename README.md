# MealTrain

No double lasagna.

When friends rally to feed a family - new baby, surgery, a hard month - somebody has to keep the calendar. MealTrain tracks who brings which meal on which night: one claim per night, coverage at a glance with the next open night, and a variety check that flags the same dish coming twice.

## Use it

Open `index.html` for the landing page, or go straight to `app.html`.

Everything runs client-side; the train is stored in the browser's localStorage. No account, no server.

## Files

- `index.html` - landing page
- `app.html` - the app
- `engine.js` - pure meal-coordination logic, shared by the app and tests

Built by the hourly app factory.
